
## 30 задач по SQL

### 🟢 Уровень 1: Разминка (1–6)

**Задача 1.** Выведи всех клиентов из Германии (`customer_country = 'Germany'`).

**Задача 2.** Найди средний возраст клиентов по каждому сегменту (`customer_segment`).

**Задача 3.** Выведи топ-10 городов по количеству клиентов.

**Задача 4.** Посчитай, сколько заказов было сделано через каждый канал продаж (`sales_channel`).

**Задача 5.** Найди все товары из категории `Electronics` дороже 500. Выведи название, бренд и цену.

**Задача 6.** Выведи клиентов, у которых `customer_acquisition_cost` больше 30.

### 🟡 Уровень 2: JOIN и агрегаты (7–12)

**Задача 7.** Выведи топ-10 клиентов по количеству заказов (`COUNT(DISTINCT order_id)`).

**Задача 8.** Для каждой категории товаров посчитай средний рейтинг (`AVG(product_rating)`). Оставь только те, где средний рейтинг > 4.

**Задача 9.** Найди топ-5 брендов по количеству товаров в каталоге. Выведи бренд и число товаров.

**Задача 10.** Посчитай средний чек (`AVG(net_sales)`) по каждому способу оплаты (`payment_method`).

**Задача 11.** Выведи все заказы со статусом `Returned` вместе с именем клиента и причиной возврата.

**Задача 12.** Найди клиентов, у которых больше 10 заказов и `is_repeat_customer = 'True'`.

### 🟠 Уровень 3: CASE WHEN и подзапросы (13–18)

**Задача 13.** Сегментируй клиентов по возрасту: `'<25'`, `'25-40'`, `'40-60'`, `'60+'`. Посчитай количество в каждом.

**Задача 14.** Раздели товары на ценовые категории: `'Premium'` (>500), `'Mid'` (200–500), `'Budget'` (<200). Выведи топ-5 товаров по цене в каждой категории.

**Задача 15.** Найди клиентов, у которых сумма покупок больше средней по всем клиентам.

**Задача 16.** Выведи заказы, где `delivery_days` больше `estimated_delivery_days` (опоздания).

**Задача 17.** Найди товары, которые продавались чаще среднего (`COUNT(*)` > среднего по всем товарам).

**Задача 18.** Найди товары, у которых `unit_price` больше средней цены по их категории.

### 🔵 Уровень 4: CTE и оконные функции (19–24)

**Задача 19.** Через CTE найди топ-10 клиентов по сумме покупок и их средний чек.

**Задача 20.** Через CTE найди топ-3 товара по прибыли в каждой категории (`ROW_NUMBER` + `PARTITION BY`).

**Задача 21.** Для каждого клиента посчитай накопительную сумму покупок по датам (`SUM() OVER`).

**Задача 22.** Сравни сумму каждого заказа с предыдущим заказом того же клиента (`LAG`).

**Задача 23.** Найди клиентов, у которых каждый следующий заказ был дороже предыдущего (все `LAG` положительные).

**Задача 24.** Для каждой категории товаров посчитай процент, который приносит топ-1 товар от общей прибыли категории.

### 🔴 Уровень 5: Сложные (25–30)

**Задача 25.** Найди клиентов, которые купили товары из всех категорий (`HAVING COUNT(DISTINCT category) = (SELECT COUNT(DISTINCT category) FROM product_catalog)`).

**Задача 26.** Для каждого месяца посчитай: выручку, количество заказов, средний чек, и динамику к предыдущему месяцу (`LAG`).

**Задача 27.** Сегментируй клиентов через `CASE WHEN` + оконные: `'VIP'`, `'Loyal'`, `'New'`, `'Lost'` — на основе суммы покупок и количества заказов.

**Задача 28.** Найди товары, которые ни разу не были возвращены (`return_status`).

**Задача 29.** Через self-join найди пары клиентов из одного города, у которых разница в возрасте меньше 5 лет.

**Задача 30 (РЕЙД-БОСС).** Когортный анализ: для каждого месяца регистрации клиента (первый заказ) посчитай, сколько клиентов вернулись в следующие 3 месяца. Используй CTE, оконные функции, `CASE WHEN`, self-join и агрегаты. Результат: месяц когорты, размер когорты, retention через 1, 2, 3 месяца.
